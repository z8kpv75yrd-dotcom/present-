# Генератор презентаций СибГИУ

Статический сайт (один файл index.html). Работает целиком в браузере, сервер не нужен.

## Как выложить на GitHub Pages
1. Создайте репозиторий на GitHub (например, `presentation-maker`).
2. Загрузите в него файлы из этой папки (index.html, .nojekyll, README.md).
3. Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
4. Через минуту сайт откроется по адресу https://ВАШ_ЛОГИН.github.io/presentation-maker/
